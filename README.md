# orienting.lu

Bilingual website for Orienting, Ting Wang's eCommerce and AI regulatory implementation advisory practice.

The English homepage introduces Ting, outlines three service areas, links to her newsletter and events, and provides an enquiry form. Regulatory answers live on the separate Resources page.

Static HTML, CSS, and JavaScript. Deployed on Vercel through the GitHub `main` branch.

See `CLAUDE.md` for positioning, brand, and current decisions.
